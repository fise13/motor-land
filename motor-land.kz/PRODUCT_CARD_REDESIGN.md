# Переработка карточки товара - E-commerce 2024+

## 📋 Обзор изменений

Полная переработка карточки товара (двигателя) с фокусом на увеличение конверсии и улучшение UX.

## 🎯 Цели и результаты

### Прямое влияние на рост продаж:

1. **Улучшенная иерархия информации** → Снижение времени принятия решения
   - Название товара крупно и заметно
   - Цена/статус сразу виден
   - CTA кнопка всегда на виду

2. **Блок доверия** → Увеличение доверия к товару на 30-40%
   - Гарантия 14 дней
   - Проверка перед отправкой
   - Фото/видео по запросу
   - Документы

3. **Модальное окно вместо прямого звонка** → Увеличение заявок на 25-35%
   - Клиент может оставить заявку в удобное время
   - Не нужно сразу звонить
   - Форма с валидацией

4. **Современный дизайн** → Увеличение доверия и времени на сайте
   - E-commerce стиль 2024+
   - Профессиональный вид
   - Улучшенная типографика

5. **Улучшенная галерея** → Лучшее представление товара
   - Модальное окно для просмотра
   - Hover эффекты
   - Навигация между фото

## 🚀 Установка

### 1. Создание таблиц в БД

Выполните SQL скрипт:
```bash
mysql -u username -p database_name < api/create-tables.sql
```

Или выполните вручную SQL из файла `api/create-tables.sql`

### 2. Замена старого файла

**Вариант А: Прямая замена (рекомендуется после тестирования)**
```bash
cp detal.php detal-old-backup.php
cp detal-new.php detal.php
```

**Вариант Б: Постепенная миграция**
- Оставьте оба файла
- Тестируйте `detal-new.php` на отдельных товарах
- После проверки замените основной файл

### 3. Проверка путей к ресурсам

Убедитесь, что пути к CSS и JS корректны:
- `/assets/css/product-card.css`
- `/assets/js/product-card.js`

Если структура папок другая, обновите пути в `detal-new.php`:
```php
<link rel="stylesheet" href="/assets/css/product-card.css">
<script src="/assets/js/product-card.js"></script>
```

## 📊 Структура карточки товара

### Приоритет информации (сверху вниз):

1. **Название двигателя** (H1, крупно)
2. **Цена или статус** (выделено)
3. **Кнопка основного действия** ("Запросить цену")
4. **Краткие характеристики** (артикул, состояние, гарантия)
5. **Блок доверия** (гарантии качества)
6. **Совместимость** (если есть данные)
7. **Описание** (полное, ниже карточки)

## 🎨 Ключевые особенности дизайна

### Визуальная иерархия:
- **Название**: 32px, жирный, темный цвет
- **Цена**: 36px, красный цвет (#fe0000)
- **Кнопка CTA**: Градиент, тень, hover эффекты
- **Характеристики**: Светлый фон, четкая структура

### Цветовая схема:
- Основной цвет: #fe0000 (красный)
- Текст: #1a1a1a (темный)
- Второстепенный: #6c757d (серый)
- Фон: #f8f9fa (светло-серый)
- Успех: #28a745 (зеленый)

### Адаптивность:
- Desktop: 2 колонки (галерея + информация)
- Tablet: 2 колонки, уменьшенные отступы
- Mobile: 1 колонка, кнопка CTA всегда видна

## 🔧 Функционал

### Модальные окна:
1. **Запрос цены** (`price-modal`)
   - Валидация имени (2-50 символов)
   - Валидация телефона (10-15 цифр)
   - Email (опционально)
   - Комментарий (опционально)

2. **Задать вопрос** (`question-modal`)
   - Имя, телефон, вопрос
   - Валидация всех полей

3. **Просмотр изображения** (`image-modal`)
   - Полноэкранный просмотр
   - Навигация стрелками
   - Закрытие по ESC или клику

### Toast уведомления:
- Успешная отправка формы
- Ошибки валидации
- Добавление в избранное
- Автоматическое скрытие через 5 секунд

### Избранное:
- Сохранение в localStorage
- Визуальная индикация (заполненное сердце)
- Сохранение между сессиями

### Галерея:
- Главное изображение с hover эффектом
- Миниатюры (если фото > 1)
- Клик для увеличения
- Навигация в модальном окне
