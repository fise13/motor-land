## Установка и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Сборка CSS
```bash
# Production
npm run build-css

# Development (watch mode)
npm run watch-css
```

### 3. Структура файлов
```
motor-land.kz/
├── assets/
│   ├── css/
│   │   ├── main.css          # Исходный файл с Tailwind директивами
│   │   └── output.css        # Скомпилированный CSS (генерируется)
│   └── js/
│       └── main.js           # Основной JS файл
├── components/
│   ├── header.php            # Компонент header
│   └── footer.php            # Компонент footer
├── index-new.php             # Новая главная страница
├── tailwind.config.js        # Конфигурация Tailwind
└── package.json              # Зависимости проекта
```

## Использование новой версии

### Вариант 1: Замена существующего index.php
```bash
# Сделайте backup
cp index.php index-old.php

# Замените на новую версию
cp index-new.php index.php
```

### Вариант 2: Тестирование на отдельной странице
Просто откройте `index-new.php` в браузере для тестирования.

## Особенности реализации

### Dropdown фильтры
- Автоматическая загрузка зависимых данных (модели для марки, годы для модели)
- Валидация последовательности выбора
- Плавные анимации открытия/закрытия

### Формы
- Валидация на клиенте и сервере
- AJAX отправка без перезагрузки страницы
- Интеграция с Google Analytics

### Адаптивность
- Mobile-first подход
- Breakpoints: sm (640px), md (768px), lg (1024px), xl (1280px)
- Оптимизированная навигация для мобильных устройств
