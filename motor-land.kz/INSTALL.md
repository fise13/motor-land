# Инструкция по установке и запуску

## Быстрый старт

### 1. Установка Node.js зависимостей

```bash
cd /Users/victor/Documents/mystic/motor-land.kz
npm install
```

### 2. Сборка CSS

Для production (однократная сборка):
```bash
npm run build-css
```

Для development (автоматическая пересборка при изменениях):
```bash
npm run watch-css
```

### 3. Проверка результата

После сборки файл `assets/css/output.css` будет создан. Этот файл нужно подключить в HTML.

## Структура проекта

```
motor-land.kz/
├── assets/
│   ├── css/
│   │   ├── main.css          # Исходный файл с @tailwind директивами
│   │   └── output.css        # Скомпилированный CSS (создается после сборки)
│   └── js/
│       └── main.js           # Основной JavaScript файл
├── components/
│   ├── header.php           # Компонент шапки сайта
│   └── footer.php           # Компонент подвала сайта
├── index-new.php            # Новая версия главной страницы
├── tailwind.config.js       # Конфигурация Tailwind CSS
├── package.json             # Зависимости проекта
└── README-REDESIGN.md       # Документация по переработке
```

## Использование новой версии

### Вариант 1: Тестирование (рекомендуется сначала)

Откройте в браузере `index-new.php` для проверки работы.

### Вариант 2: Замена существующей версии

```bash
# Создайте резервную копию
cp index.php index-backup.php

# Замените на новую версию
cp index-new.php index.php
```

## Важные замечания

1. **CSS файл**: Убедитесь, что `assets/css/output.css` создан после сборки
2. **Пути**: Все пути в PHP файлах используют абсолютные пути от корня сайта
3. **База данных**: Новая версия использует те же функции из `hyst/php.php`, что и старая
4. **Совместимость**: Новая версия полностью совместима с существующей базой данных

## Разработка

### Добавление новых стилей

Редактируйте `assets/css/main.css` - добавляйте кастомные классы в секции `@layer components` или `@layer utilities`.

### Изменение цветовой палитры

Отредактируйте `tailwind.config.js` в секции `theme.extend.colors`.

### Добавление новых компонентов

Создавайте новые PHP файлы в папке `components/` и подключайте их через `include()`.

## Troubleshooting

### CSS не применяется

1. Убедитесь, что выполнили `npm run build-css`
2. Проверьте, что файл `assets/css/output.css` существует
3. Проверьте пути в HTML (должен быть `/assets/css/output.css`)

### Dropdown не работает

1. Проверьте, что `assets/js/main.js` подключен
2. Убедитесь, что в консоли браузера нет ошибок JavaScript
3. Проверьте, что функция `initDropdowns()` вызывается

### Формы не отправляются

1. Проверьте путь к `send_form.php`
2. Убедитесь, что все обязательные поля заполнены
3. Проверьте консоль браузера на наличие ошибок

## Production deployment

1. Выполните `npm run build-css` для финальной сборки
2. Убедитесь, что `assets/css/output.css` минифицирован
3. Проверьте все пути на корректность
4. Протестируйте на всех устройствах
